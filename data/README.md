| 수집 경로 | [FinanceData/marcap](https://github.com/FinanceData/marcap): KRX 전종목 시세를 연도별 parquet 파일로 정리해 GitHub Actions로 매일 갱신하는 공개 저장소 |

| 사용 파일 | `data/marcap-2022.parquet` ~ `data/marcap-2026.parquet` 5개 (SHA-256은 `src/config.py`와 `data/manifest.json`에 기록) |

## 2. 수집 방법

```bash
python -m src.fetch_data            # 고정 커밋에서 내려받아 data/raw/ 를 다시 만든다
```

1. 연도별 parquet 5개를 `https://raw.githubusercontent.com/FinanceData/marcap/<커밋>/data/marcap-<연도>.parquet`에서 내려받아 `data/cache/`에 보관한다(약 120MB, 저장소에는 올리지 않음).
2. 내려받은 파일의 SHA-256이 기록된 값과 다르면 멈춘다. 같은 커밋이면 언제 받아도 같은 파일이 나온다.
3. 삼성전자(005930)·SK하이닉스(000660) 행만 뽑아 `raw/krx_daily_005930_000660.csv`로 저장한다.
4. KOSPI 상장 보통주 전체로 시장 수익률을 계산해 `raw/kospi_market_daily.csv`로 저장한다.
5. 결과 파일의 행 수·기간·SHA-256을 `manifest.json`에 기록한다. `tests/test_data_quality.py`가 이 해시로 원자료가 바뀌지 않았는지 확인한다.

## 5. KOSPI 재계산 검증

공식 KOSPI는 유가증권시장 보통주의 시가총액식 지수다(지표누리 설명). 같은 정의로 다시 계산한 값을 2022-12-29 공식 종가 2,236.40에서 출발시켜 보도된 공식 종가와 비교했다.

- 종가 14개 시점: 차이 최대 0.17%, 평균 0.11%
- 하루 등락률 10개 시점: 차이 최대 0.011%p
- 시가총액 합계 2개 시점(2026-06-22, 2026-10-12): 보도 수치와 1억 원 단위까지 일치

전체 대조표는 `results/tables/checkpoint_validation.csv`에 있다. 작은 차이의 원인은 확인하지 않았다. 공식 지수는 신규 상장·증자 때 기준 시가총액을 조정하는데, 이 계산은 전일 시가총액 가중 방식이라 그 차이가 쌓였을 가능성이 있다(가설).

## 7. 라이선스와 이용 주의

- 시세 데이터의 원 권리는 한국거래소에 있다. 이 저장소는 학습·비상업 목적의 재현성을 위해 두 종목의 일별 시세와 KOSPI 집계값만 담았다. 상업적 이용이나 재배포 전에는 KRX 정보데이터시스템의 이용 조건을 확인해야 한다.
- FinanceData/marcap 저장소에는 라이선스 파일이 없다(커밋 `eeed081` 기준).
- `reference/` 의 언론 보도 수치는 날짜·수치 확인용으로만 쓰며, 기사 본문은 옮기지 않고 링크만 남겼다.
